# Support

Start with the [quick start](README.md#quick-start) and [troubleshooting guide](docs/troubleshooting.md). For usage questions that are not defects, open a GitHub Discussion if enabled or a concise issue using the closest template.

Include the following details when reporting a reproducible bug.

- DevTools, Axolotl-PM, API and PHP versions
- operating system
- the smallest relevant `plugin.yml`, `devtools.yml`, or `virion.yml`
- exact reproduction steps
- expected and actual results
- a sanitized log excerpt

Remove addresses, tokens, passwords, cookies, paths revealing private usernames, and unrelated plugin data. Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public issue.

Only the latest release receives fixes. General PHP and plugin development, other server runtimes, network downloads, package publishing, and hot reload are outside project support.
