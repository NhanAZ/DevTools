# Code of conduct

Be respectful, specific, and focused on the technical work. Harassment, discrimination, threats, doxxing, spam, and publishing another person's private data are not accepted in project spaces.

Assume good faith while reviewing ideas, but criticize behavior or code rather than people. Maintainers may edit, hide, reject, or ban participation that makes the project unsafe or unproductive.

Report conduct concerns privately through the maintainer contact mechanism shown on the GitHub profile. Do not open a public issue containing sensitive personal details.
